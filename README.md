 Healthcare Financial Analysis Dashboard 🏥📊

An end-to-end data analytics and visualization solution analyzing healthcare financial metrics, claims processing, and member data using SQL and Power BI.

---

## 📌 Project Overview

This project provides an interactive dashboard designed to evaluate financial metrics, claims distributions, and demographic trends within a healthcare dataset. By integrating database querying with dynamic dashboard visualizations, it offers actionable insights into insurance claim costs, member statistics, and financial risk profiles.

---

## 🛠️ Tech Stack & Tools

* **SQL:** Data querying, aggregation, and preprocessing (`SQLQuery2.sql`).
* **Power BI:** Interactive data modeling and visualization (`Project23.pbix`).
* **Datasets:** Structured tabular claims and member data (`claims.csv`, `members.csv`).

## 🚀 Getting Started

### Prerequisites

* [Power BI Desktop](https://powerbi.microsoft.com/) installed to open and view `.pbix` dashboard files.
* Any SQL Database Environment (SQL Server, MySQL, PostgreSQL) to execute `.sql` queries.

### Usage

1. **Clone the repository:**
```bash
git clone [https://github.com/mussabafridi/Healthcare-Financial-Analysis-Dashboard.git](https://github.com/mussabafridi/Healthcare-Financial-Analysis-Dashboard.git)

```


2. **Database Queries:** Open `SQLQuery2.sql` in your SQL environment to view or execute data preprocessing queries against `claims.csv` and `members.csv`.
3. **Power BI Dashboard:** Open `Project23.pbix` in Power BI Desktop to inspect the interactive visualizations, data models, and financial measures.
